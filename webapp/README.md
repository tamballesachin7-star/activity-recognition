# Activity Recognition Web App — GNDEC AIML

**Spatiotemporal Human Activity Recognition using 3D CNN & Grad-CAM**  
*Department of AI & ML, Guru Nanak Dev Engineering College, Bidar*

## Features
- 🎥 **Live Camera** — real-time activity prediction via your webcam
- 📁 **Upload Video** — analyze any MP4/AVI/MOV video
- 🧠 **3D CNN + Grad-CAM** — deep learning backbone
- 🌐 **Flask Web App** — deployable anywhere

## Run Locally
```bash
cd webapp
pip install -r requirements.txt
python app.py
# Open http://localhost:5000
```

## Deploy to Railway
1. Push this repo to GitHub (already done)
2. Go to [railway.app](https://railway.app) → New Project → Deploy from GitHub
3. Select this repo and set **Root Directory** to `webapp`
4. Railway auto-detects the Procfile and deploys!
